# Sprint 1 — Foundation

## Goal
Create a clean, responsive and extensible public foundation for PREFAB.LV.

## Acceptance criteria
- Homepage renders on desktop, tablet and mobile.
- Navigation links scroll to the correct sections.
- Mobile menu opens and closes.
- Login route is available at `/login`.
- Company branding and contact data are included.
- Project can be built with `npm run build`.

## Next sprint
Public content pages, real project media, multilingual routing and functional contact submission.
