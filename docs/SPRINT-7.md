# Sprint 7 — Project Management Core

Version: `v0.7.0-alpha.1`

## Delivered
- Create and edit projects with client, location, schedule, status, responsible manager and notes.
- Assign existing employees to projects with project-specific roles, and remove assignments.
- Create, edit, update and delete project deliveries.
- Create, assign, prioritize, resolve, close and delete project issues.
- Permission enforcement for project and operational changes.
- Activity log entries for important project changes.
- Project Hub upgraded into the central operational workspace.

## Permissions
- Director, Administrator and Project Manager can manage project details and membership.
- Foreman and higher can manage deliveries and issues.
- Destructive delivery and issue actions require Project Manager or higher.

## Deferred
- Notifications.
- New file and photo upload infrastructure.
